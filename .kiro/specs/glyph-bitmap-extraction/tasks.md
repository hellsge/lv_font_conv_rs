# 实现计划

## 概述

本实现计划将 glyph bitmap 提取功能集成到 lv_font_conv 中。核心功能已完成，包括 CLI 参数、二进制提取逻辑、多文件输出和文档更新。剩余任务主要是可选的属性测试，用于全面验证功能的正确性。

## 已完成的任务

- [x] 1. 添加 CLI 参数和验证逻辑
  - 在 `lib/cli.js` 中添加 `--extract-glyph-bitmap` 参数
  - 添加参数验证：仅在 `--format lvgl` 时允许使用
  - 添加帮助文档说明
  - _需求：3.1, 3.2, 3.4_

- [x] 2. 扩展 LvGlyf 类以支持二进制提取
  - 在 `lib/writers/lvgl/lv_table_glyf.js` 中实现 `toBinaryFile()` 方法
  - 实现 `toLVGLWithExternalBitmap(macroName)` 方法生成宏引用版本的 C 代码
  - 修改 `toLVGL(extractBitmap, macroName)` 方法支持条件分支
  - 确保二进制文件包含所有 glyph bitmap 数据（跳过 id=0）
  - _需求：1.1, 1.3, 2.4, 5.1, 5.2_

- [x] 3. 修改 LvFont 类传递提取标志
  - 在 `lib/writers/lvgl/lv_font.js` 中修改 `toLVGL(extractBitmap)` 方法签名
  - 将 `extractBitmap` 和 `font_name` 传递给 `glyf.toLVGL()`
  - 确保生成的 C 代码包含正确的宏名称
  - _需求：1.4, 2.1_

- [x] 4. 修改 LVGL Writer 接口以支持多文件输出
  - 在 `lib/writers/lvgl/index.js` 中修改返回值逻辑
  - 检测 `args.extract_glyph_bitmap` 标志
  - 生成二进制文件名：`{baseName}_glyph_bitmap.bin`
  - 返回包含 C 文件和二进制文件的对象
  - 确保二进制文件与 C 文件在同一目录
  - _需求：1.2, 2.5, 3.5_

- [x] 5. 添加成功输出报告
  - 在 `lib/cli.js` 中添加文件生成报告逻辑
  - 列出所有生成的文件（C 文件和二进制文件）
  - _需求：3.3_

- [x] 6. 创建功能文档
  - 创建 `EXTENDED_FEATURES.md` 综合文档
  - 添加 `--extract-glyph-bitmap` 参数说明
  - 添加 `--pixel-order` 参数说明
  - 添加使用示例（如何定义宏地址、像素顺序配置）
  - 说明嵌入式 flash 使用场景
  - 添加故障排除和高级用法
  - _需求：3.1_

- [x] 7. 编写基础属性测试
  - 创建 `test/test_extract_glyph_bitmap.js` 测试文件
  - 实现属性 1 测试：二进制文件内容一致性
  - 实现属性 4 测试：宏引用替换
  - _需求：1.1, 1.3, 2.3, 2.4, 4.1, 4.2, 4.5, 5.1, 5.2_
